# My Healthy Journey PWA
A mobile-friendly installable 30-day Saint Lucian meal planner. Uses local browser storage for checklists, progress, water tally and notes.

## Install on Android
This app needs to be hosted on HTTPS (or localhost) to be installable. Easiest free option:
1. Create a GitHub repository and upload all files from this folder.
2. In repo Settings → Pages, deploy from the main branch/root.
3. Open the Pages URL in Chrome on Android.
4. Chrome menu ⋮ → Install app (or Add to Home screen) → confirm.
5. Open the new home-screen icon.

After the first load, it caches the app for offline use. All tracker data remains local to the browser/device; no user account or server is used.
